## When Should You Use PNG, JPG, or WebP?

| Format | Recommended Use |
|---|---|
| PNG | Transparent backgrounds, graphics, and cutout images |
| JPG | Photographs where transparency is not required |
| WebP | Web images where efficient file sizes are useful |

PNG is usually the better choice when background transparency must be preserved.
